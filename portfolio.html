About

I build playful, information-rich web experiences around things people are curious about.

My work sits between game design, front-end development, and learning design. I like projects with a clear hook, a lot of hidden depth, and enough personality that players remember them. Sharkdle is the main example: a simple guessing loop that has grown into modes, rewards, species references, mobile support, and live updates.

Featured case study

Sharkdle

Live web game

A daily shark identification game that expanded into a full player ecosystem.

Sharkdle began with a simple challenge: guess the shark. The project now supports daily, practice, infinite, story, and minigame modes, with achievements, profile themes, cosmetic collections, Sharkpass progression, leaderboards, and Firebase-backed player data.

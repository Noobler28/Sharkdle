# Sharkdle Mobile Release

### Currently, Sharkdle Mobile is available on Android only. An iOS release is planned for the future.

## Download the latest Sharkdle Mobile App below.

The app automatically checks for updates and will direct you here when a new version is available.

## To Install and Update

Download the latest version for your device.

Open the downloaded file or installation link.

Follow the on-screen instructions to **install** or **update** Sharkdle.

Updating will not affect your saved progress or settings.

**Android Note**: Because Sharkdle is currently distributed directly as an APK and not through the Google Play Store, Android or Google Play Protect may display a security warning. This is expected. Only proceed if you downloaded the APK from this official Sharkdle release page.
